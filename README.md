PROYECTOS RELACIONADOS A N8N 

Los proyectos que hay aqui son del clima de cali en la actualidad con n8n y un archivo n8n que sirve para guardar las noticias mas importantes del momento en html. El n8n sirve para automatizar software usando apis y activadores. Se integraran diferentes aplicaciones con este orquestador. Con el fin de poner a funcionar el software se necesita descargar javascript y npm con el fin de luego 8n8. COn el fin de ejecutar los siguientes softwares se puede dar click en la opcion dowload de color verde o tambien se puede descargar el repositorio con:

```Terminal de comandos
git init
git clone https://github.com/guevaraStian/N8N.git
cd N8N
git push origin master
```
