PROYECTOS RELACIONADOS A N8N 

Los proyectos que hay aqui son del clima de cali en la actualidad con n8n y un archivo n8n que sirve para guardar las noticias mas importantes del momento en html. El n8n sirve para automatizar software usando apis y activadores. Se integraran diferentes aplicaciones con este orquestador. Con el fin de poner a funcionar el software se necesita descargar javascript y npm con el fin de luego 8n8. 


Con el fin de ejecutar los siguientes softwares se puede dar click en la opcion dowload de color verde o tambien instalando git y proceder a descargar el repositorio con los siguientes comandos de consola:

```Terminal de comandos
git init
git clone https://github.com/guevaraStian/N8N.git
cd N8N
git push origin master
```

Luego de tener descargado el codigo de programacion dentro de cada json, se procede a abrir n8n y ejecutar el codigo.
